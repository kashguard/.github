# KashGuard 数字资产管理产品线

**KashGuard = Key + Cash + Guard**  
我们以密钥（Key）管理为核心，守护数字现金（Cash）安全，为企业与个人提供可信赖的数字资产守护（Guard）解决方案。

## 🌐 愿景与使命

我们致力于构建下一代安全、可监管、可扩展的数字资产管理基础设施，覆盖从核心密码技术到终端产品的全链路能力。

- **统一基座**：以分布式密钥管理与安全硬件为底座，构建一致的安全模型与可信环境。
- **场景驱动**：围绕 2B 托管、多签、交易所风控，以及 2C 自托管、智能钱包等高频场景持续迭代。
- **工程落地**：提供开放 API / SDK、自动化运维工具链与合规配套，助力客户快速实现产品上线。

## 🧱 产品矩阵

| 层级 | 产品 | 简要说明 | 优先级 |
|------|------|----------|---------|
| 基础设施 | **KMS** | 去中心化密钥管理服务，支持多链签名与密钥轮换 | P0 |
| 基础设施 | **HMS** | 硬件与 HSM 管理平台，统一固件、证书与远程运维 | P1 |
| 核心技术 | **MPC Stack** | 多方安全计算与阈值签名实现（GG18/20、FROST） | P0 |
| 钱包产品 | **企业多签钱包** | 面向机构审批、风控与审计的多签账户体系 | P0 |
| 钱包产品 | **托管钱包** | 面向托管服务商与交易所的运营套件 | P0 |
| 钱包产品 | **自托管钱包** | 2C 场景，注重易用性与社交恢复 | P1 |
| 钱包产品 | **智能钱包** | 账户抽象与 MPC 结合的下一代钱包 | P1 |
| 硬件终端 | **硬件钱包** | 面向高净值用户与机构的签名终端及配套 SDK | P2 |

## 🗂️ 代码与文档结构

- `go-kms/`：MPC/KMS 核心服务实现（Go）
- `docs/`（筹）：API 设计、架构说明与运维手册
- `wallet-*`（规划中）：各类钱包前后端实现
- `hardware/`（规划中）：硬件固件与管理工具
- 根目录 Markdown 文件：产品规划、路线图、API 设计等文档

## 🧭 发展路线图

- **第一阶段**：完成 KMS 与 MPC 核心模块 MVP，推出企业多签钱包 Beta 版本，支持 BTC/ETH 主流链。
- **第二阶段**：扩展多链支持，上线托管钱包与 HMS 平台，提升系统性能至签名延迟 <300ms、吞吐量 500+ TPS。
- **第三阶段**：推出智能钱包量产版本，发布硬件钱包产品，形成自营服务与 SaaS 双线商业模式。
