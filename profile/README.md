# KashGuard数字资产管理产品线 

我们在此组织下协同开发一整套面向企业与个人的数字资产管理产品，覆盖基础设施、核心密码技术、钱包形态及硬件终端，目标是交付安全、可监管、可规模化的资产管理能力矩阵。

## 🌐 愿景与使命
- **统一基座**：以分布式密钥管理与安全硬件为底座，提供一致的安全模型。
- **场景驱动**：围绕 2B 托管、多签、交易所风控，以及 2C 自托管、智能钱包等高频场景迭代。
- **工程落地**：开放 API / SDK、自动化运维工具链与合规配套，缩短产品上市周期。

## 🧱 产品矩阵
| 层级 | 产品 | 简要说明 | 优先级 |
| --- | --- | --- | --- |
| 基础设施 | **KMS** | 去中心化密钥管理服务，支撑多链签名/轮换 | P0 |
| 基础设施 | **HMS** | 硬件与 HSM 管理平台，统一固件、证书、远程运维 | P1 |
| 核心技术 | **MPC Stack** | 多方安全计算与阈值签名实现（GG18/20、FROST） | P0 |
| 钱包产品 | **企业多签钱包** | 面向机构审批、风控与审计的多签账户体系 | P0 |
| 钱包产品 | **托管钱包** | 托管服务商/交易所的托管运营套件 | P0 |
| 钱包产品 | **自托管钱包** | 2C 场景，注重易用、社交恢复 | P1 |
| 钱包产品 | **智能钱包** | 账户抽象 + MPC 结合的下一代钱包 | P1 |
| 硬件终端 | **硬件钱包** | 面向高净值/机构的签名终端及配套 SDK | P2 |

## 🧭 三年路线图快照
- **Year 1**：交付 KMS & MPC MVP、企业多签钱包 Beta，打通 BTC/ETH；团队 30-40 人。
- **Year 2**：扩展至多链、上线托管钱包与 HMS，性能 <300ms、500+ TPS；团队 50+ 人。
- **Year 3**：智能钱包量产、硬件钱包版本发布，形成自营与 SaaS 双线收入；团队 60-80 人。
